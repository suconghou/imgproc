image-engine

基于 wasm-vips（libvips 的 WebAssembly 版）的浏览器端图片处理工具包。 缩放 / 裁剪 / 旋转 / 格式转换全部在本机完成，图片不上传。

在别的站点引用

<!-- 1. 跨源引用本 CDN 上的工具包（引擎会自动处理 Worker 的同源限制） -->
<script src="https://imgproc.<你的子域>.workers.dev/image-engine/image-engine.js"></script>

<!-- 2. 你的页面必须处于跨源隔离状态，否则引擎不会初始化 -->
<script>
  ImageEngine.create().then(async (engine) => {
    const out = await engine.convert(file, {
      format: 'webp', quality: 80,
    })
    document.querySelector('img').src = URL.createObjectURL(out.blob)
  })
</script>

第 2 步的「跨源隔离」靠两个响应头实现，加在你的页面上（不是本 CDN）：

# Nginx
add_header Cross-Origin-Opener-Policy same-origin;
add_header Cross-Origin-Embedder-Policy require-corp;

也可以把整个文件夹拷进你自己的项目（同源使用，不必依赖本域名）—— 见 image-engine/README.md。
